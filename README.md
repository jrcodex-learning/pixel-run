# Pixel Run

A small platformer game in Python: run, jump, collect coins, stomp enemies and reach the flag.
Then put it online so anyone can play it in a browser.

This is the starter project for the JrCodex project **Build a platformer game**. Follow the
chapters there; this folder is where you'll build it.

## What's here

- `.gitignore`: files Git should never save (your virtual environment and build files).

There is no code yet. You'll write all of it, one chapter at a time, in one file: `main.py`.

## Stuck, or want to compare?

Each chapter's finished code is saved under a tag: `ch02`, `ch03`, and so on.

- Compare your code with the end of chapter 6: `git diff ch06`
- See it on GitHub: switch the branch menu to the tag `ch06`
